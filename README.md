# Sales Performance Dashboard (Power BI)

## Objective
Analyze sales performance and identify key trends in revenue, profit, and order distribution.

## Tools Used
- Power BI
- Data Visualization

## Key Features
- KPI metrics for Sales, Profit, and Orders
- Sales analysis by category and region
- Monthly sales trend visualization
- Top-performing products analysis
- Interactive filters for dynamic insights

## Insights
- Identified top-performing product categories
- Observed regional sales distribution patterns
- Analyzed monthly sales trends for business planning
